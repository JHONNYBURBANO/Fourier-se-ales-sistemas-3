# Proyecto Fourier - Señales y Sistemas

Aplicación desarrollada en Python para reconstruir señales periódicas mediante series de Fourier.

## Requisitos

- Python 3.11
- Matplotlib
- Tkinter (incluido normalmente con Python en Windows)

## Ejecución

1. Descargar el archivo `codigo_proyecto_fourier-3.py`.
2. Abrir una terminal en la carpeta donde se descargó.
3. Ejecutar:

```cmd
python codigo_proyecto_fourier-3.py
```

## Funcionalidades

- Selección de señales cuadrada, triangular y diente de sierra.
- Reconstrucción mediante series de Fourier.
- Selección del número de armónicos.
- Modificación del intervalo temporal.
- Visualización de cuatro gráficas.
- Cálculo del RMSE y las potencias promedio.
- Validación de entradas incorrectas.

## Bibliotecas utilizadas

- math
- fractions
- tkinter
- matplotlib
